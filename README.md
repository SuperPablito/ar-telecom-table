# AR Telecom Table (recreation)

Interactive 3D explainer of how 5G works: 7 scenes (How 5G works, Beamforming, Open RAN, Massive MIMO, Handover, Low latency, Project demo), MACRO / MIDDLE / MICRO scale and L1 / L2 / L3 software layers.

Live: https://superpablito.github.io/ar-telecom-table/

Recreated from the original concept: https://geemu-studio.github.io/ar-telecom-table/

Single self-contained `index.html` (three.js r128 inlined, MIT licence). KPI values in the demo scene are examples.
